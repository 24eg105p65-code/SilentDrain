# SilentDrain

## Subscription & Hidden Payment Detection System

SilentDrain is a local-first financial analysis application
designed to identify recurring payments, subscription candidates,
possible hidden payments, and spending patterns from bank statements.

## Technology Stack

- Python
- Streamlit
- SQLite
- Pandas
- PyMuPDF
- OpenPyXL
- Plotly

## Main Features

- Bank Statement Upload
- Transaction Processing
- Merchant Identification
- Recurring Payment Detection
- Subscription Identification
- Hidden Payment Detection
- Financial Analytics
- Report Generation

## Application Type

Desktop-first local web application.
